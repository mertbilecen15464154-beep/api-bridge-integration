# api-bridge-integration
Real-time webhook and API gateway integration dashboard for connecting external services, CRM systems, and automated notifications.
# 🌐 APIBridge Pro - Sistemler Arası API & Webhook Entegrasyon Paneli

APIBridge Pro, farklı web servislerinden (E-Ticaret, Ödeme Sistemleri, İletişim Formları) gelen webhook isteklerini yakalayan, verileri doğrulayan ve hedef sistemlere (CRM, WhatsApp API, SQL Veritabanları) aktaran modern bir entegrasyon arayüzüdür.

---

## ✨ Öne Çıkan Özellikler

- ⚡ **Gerçek Zamanlı Webhook Dinleyici:** Gelen HTTP POST isteklerini anında konsola loglar.
- 🔄 **Veri Doğrulama (Payload Validation):** JSON verilerini otomatik doğrular ve hedef servislere yönlendirir.
- 📊 **Canlı Log Konsolu:** Sistem hareketlerini, bağlantı durumlarını ve HTTP yanıt kodlarını (200 OK vb.) takip eder.
- 📱 **Tam Duyarlı Arayüz:** Dark mode odaklı, Tailwind CSS ve Font Awesome ile güçlendirilmiş modern panel.

---

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **Icons & Fonts:** Font Awesome 6, Google Fonts (Inter)
- **Mimari:** RESTful API & Webhook Simulation
